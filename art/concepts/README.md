# 표류도 — 그래픽 컨셉 확인

상태: 2026-10-03 사용자 승인 완료. 사용자의 ‘딱 좋아’ 확인에 따라 이 이미지의 밝기와 사용 흔적을 제작 기준으로 채택했다. 전체 리소스는 `../production/v01/`에 제작한다.

## 1차 컨셉

- 파일: `ch01_warehouse_mood_v01.png`
- 실제 크기: 1145 × 1374 px, PNG, 약 2.38 MB. 확대나 크롭 없이 생성 원본을 저장했다.
- 용도: 1챕터 창고의 색감·밝기·노후 정도·2D 표현을 확인하기 위한 컨셉 이미지.
- 제작 방식: 내장 image_gen 이미지 생성 도구, 신규 이미지 1장, 불투명 배경.
- 최종 입력 프롬프트: `ch01_warehouse_mood_v01.prompt.txt`
- 참조 범위: 검은방 3의 긴장감 있는 탐색과 미스터리 분위기. 공간·소품·구도는 독립적으로 디자인한다.

## 이번 요청으로 조정한 방향

낡았지만 사용할 수 있는 창고를 표현한다. 마른 바닥, 온화한 낮빛, 밝은 회색 벽, 회녹색 선반, 청회색 철제 캐비닛, 소량의 황토색 소품을 사용한다. 작은 흠집과 사용 흔적으로 세월을 보여 주고, 카메라·스피커·잠금장치로 긴장감을 만든다. 습기·곰팡이·물웅덩이·심한 부식·과도한 어둠은 피한다.

기존 `docs/03_ART_UI_GUIDE.md`의 축축하거나 어두운 표현보다 이 요청의 방향을 우선한다. 구체적인 색감과 표현 수준은 컨셉 확인 후 확정한다.

## 이후 실제 게임 리소스로 제작할 때

이 파일은 분위기 확인용으로, 최종 플레이 배경이나 소품별 투명 레이어를 대신하지 않는다. 확인 후 배경, 획득 가능한 아이템, 잠금장치의 열림·닫힘 상태, 퍼즐 확대 화면, 인물, UI를 각각 분리 제작한다. 선반 개수와 배치, 좌표, 퍼즐 정답은 확정된 챕터 명세에 맞춰 별도로 검수한다. 숫자·문자·암호는 이미지에 그려 넣지 않고 게임의 텍스트 레이어로 표시한다.

## 확인할 사항

1. 낮빛과 그림자의 밝기가 적절한가.
2. 벽과 소품의 낡은 정도가 적절한가.
3. 현대적인 고해상도 2D 배경의 묘사 수준이 원하는 방향인가.

확인 완료 후 본 제작을 진행한다. 추가 수정은 원본을 보존하고 새 버전 파일로 저장한다.
