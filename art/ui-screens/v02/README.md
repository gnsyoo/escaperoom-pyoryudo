# 표류도 완성 UI 이미지 v02

전반적인 글꼴을 Pretendard Variable 1.3.9로 통일했다. React 실행 화면을 실제 렌더링해 캡처한 이미지이며 PNG 안의 한국어도 같은 글꼴로 표시된다. 기존 v01은 이전 글꼴의 작업 기록이다. 현재 기준은 이 v02 폴더다.

[이미지 전체 보기](gallery.html) · [화면 메타데이터](manifest.json) · [폰트 라이선스](fonts/OFL.txt)

19개 화면은 360×780 CSS px의 3배 밀도로 저장한 1080×2340 PNG다. 2개는 사용자가 요청한 기존 390×844 구도 재제작이다. 5개는 스크롤 영역 전체를 펼친 긴 PNG로, 내용 누락 없이 화면 구성을 확인할 수 있다.
